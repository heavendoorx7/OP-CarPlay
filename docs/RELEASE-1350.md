# OP CarPlay v0.7 · 1350

修复部分车机点击「选择证书」「选择私钥」或「选择图片」时闪退的问题，并补齐系统页面不可用时的处理。

- 系统缺少文档选择器时，尝试文件管理器的选择入口。
- 两种入口均不可用时提示用户，保留原选择。
- 选择的文件在后台导入应用私有目录，不依赖文件管理器的长期读取授权。
- 取消、读取失败或读取期间放弃设置时，保留原选择；空文件和超过 1 MB 的文件会被拒绝。
- 图片选择入口不可用时，尝试系统文档选择器；两者均不可用时提示用户。取消、图片不可读或裁剪页打不开时保留原图标。
- 修复裁剪页收到无图片请求、提前退出时的未初始化异常。
- VPN、麦克风、位置、无线权限及蓝牙设置页面打不开时，给出提示并清理等待状态；不会将失败视为授权成功。显示模式切换失败时保留当前页面。
- 成功连接、仪表投放、热点及 ADB/Shizuku 授权流程保持原样。没有新增存储权限，公开 APK 不内置证书或私钥。

本地已在 Android 11 模拟器复现旧包证书及图片选择的 `ActivityNotFoundException`。本版通过 27 项界面回归：7 项证书/私钥场景、7 项图片选择场景、3 项页面缺失/提前退出场景、1 项 VPN 启动异常及 9 项权限页面启动异常。文件和图片流程使用合成测试文件；VPN 和权限页面异常使用测试注入，不代表真实车机的授权或连接验收。

另有 285 项单元测试通过、1 项仅适用于私有素材的测试跳过，Release Lint 无错误。尚未在反馈车辆实测。

安装包沿用 1349 的签名，可直接覆盖更新并保留设置，无需先卸载。附件提供 APK、对应完整源码和 SHA-256 校验文件。
