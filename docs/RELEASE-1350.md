# OP CarPlay v0.7 · 1350

修复部分车机点击「选择证书」或「选择私钥」时闪退的问题。

- 系统缺少文档选择器时，尝试文件管理器的选择入口。
- 两种入口均不可用时提示用户，保留原选择。
- 选择的文件在后台导入应用私有目录，不依赖文件管理器的长期读取授权。
- 取消、读取失败或读取期间放弃设置时，保留原选择；空文件和超过 1 MB 的文件会被拒绝。
- 连接、仪表投放、热点和授权逻辑保持原样。没有新增存储权限，公开 APK 不内置证书或私钥。

本地已在 Android 11 模拟器复现 1349 的 `ActivityNotFoundException`。1350 通过 7 项文件选择与导入场景验证，涵盖选择器缺失、取消、读取失败和重启应用后读取；另有 285 项单元测试通过、1 项跳过，Release Lint 无错误。

安装包沿用 1349 的签名，可直接覆盖更新并保留设置，无需先卸载。附件提供 APK、对应完整源码和 SHA-256 校验文件。尚未在反馈车辆实测。
