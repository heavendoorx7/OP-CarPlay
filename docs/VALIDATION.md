# 验证范围

版本：v0.7 / build1349。验证日期：2026-10-20。

## 本地验证

- 公开源码完成 Release 构建；common/mobile Release Lint 无错误。
- 279 项 JVM 用例中，278 项通过，1 项依赖个人认证材料的可选测试因公开构建不提供该材料而跳过；无失败。
- APK 没有个人认证证书、私钥和签名私钥。产物摘要见 Release 说明。
- 公开 APK 与个人安装版使用相同的生产源码和签名身份；公开构建不注入个人认证文件。

## 实车范围

**仪表盘导航仅测试了高德地图，其他地图应用未验证。**

E28 / Android 9 上已观察到无线 CarPlay、分屏/全屏、居中的真实仪表第二路投放、退出后原车小地图恢复，以及已有授权下再次打开自动投放。

车道条清除接口已获用户视觉确认。当前集成版实际按原车请求输出660×660、5fps，帧数和清除调用计数持续增加，不需要新的原车车道事件才能清除。

接口调用计数不等于人眼显示验收。个人认证配置下的实车结果也不等于所有用户对公开 APK 的首次配置已经验证。
