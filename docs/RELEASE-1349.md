# OP CarPlay v0.7 · 1349

适配搭载高通骁龙 820A 芯片的老款小鹏 P7（Android 9）。**仪表盘导航仅测试高德地图，其他地图应用未验证。**

## 功能

- 无线 CarPlay，支持原车分屏、保留系统栏的全屏及完全全屏。
- 中文分类设置，五指收拢或三指下滑呼出设置。
- 可选自动开启原车热点，支持本机 ADB 和 Shizuku 授权。
- 独立仪表地图与居中显示，退出后恢复原车地图。
- 可在 OP 投放期间隐藏原车蓝色车道条；退出后按缓存或原车后续更新恢复。

## 安装

下载 APK，通过车机已有的安装入口安装。发行 APK 不内置认证证书或私钥，首次使用需自行配置认证。

详细配置见 [使用说明](https://github.com/heavendoorx7/OP-CarPlay/blob/main/docs/USAGE.md)。
