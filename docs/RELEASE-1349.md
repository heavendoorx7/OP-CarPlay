# OP CarPlay v0.7 · build 1349

面向老小鹏 P7（E28 / Android 9）的最终功能快照。**仪表盘导航功能仅测试高德地图，其他地图应用未验证。**

## 最终功能

- 无线 CarPlay；原车分屏、带系统栏全屏、完全全屏。
- 中文分类设置、五指收拢/三指下滑呼出设置。
- 可选原生热点自动恢复；保留本机 ADB 和 Shizuku 两种已有权限入口。
- 独立仪表地图、居中取景、退出后原车小地图重建。
- OP 投放时立即隐藏原车蓝色车道条，投放期间维持；退出有缓存则尝试恢复，无缓存则等待原车下一次更新。
