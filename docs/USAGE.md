# 使用说明

## 首次连接

1. 下载并安装 APK。
2. 打开车机原生热点，在 OP 的 Wi-Fi 会话设置中选择原生/手动热点，填写实际名称、密码和安全类型。
3. 配置认证方式。本地文件认证需要配套的 DER PKCS#7 证书 `.p7b` 和未加密 DER PKCS#8 私钥 `.pk8`；也支持硬件或远程认证。发行 APK 不内置认证文件，需使用自己有权使用的材料。
4. 将 iPhone 与车机蓝牙配对，按系统提示授予所需权限，保存设置并连接。

## 显示模式与手势

- **分屏：** 通过原车分屏入口将 OP 放在右侧，左侧保留原车导航。
- **保留系统栏的全屏：** OP 适配原车顶部、底部和左侧栏占用后的显示区域。
- **完全全屏：** 隐藏原车状态栏与 Dock。

通过画面上的小图标切换；启动默认模式在设置中选择，初始为完全全屏。尺寸切换可能触发重新连接。

在 CarPlay 区域内五指张开放下、向内收拢，或三指下滑，可呼出设置。修改后保存生效。

## 自动开启原车热点

此选项默认关闭，复用原车热点已有的名称、密码和频段，不改变热点配置。原车热点为 5 GHz 时继续使用 5 GHz。

启用前，可在 OP 中选择一种授权方式：

- **本机 ADB：** 车机网络 ADB 已开启，且调试授权弹窗已允许 OP 的连接。电脑获得的授权不能代替 OP 自身的授权。
- **Shizuku：** Shizuku 已运行，并在授权弹窗中允许 OP。车机重启后可能需要重新启动 Shizuku。

热点授权仅针对 OP 的 `WRITE_SETTINGS` 操作。也可通过电脑授权：

```bash
adb shell cmd appops set --user 0 com.shilapi.xcertplay.p7 WRITE_SETTINGS allow
adb shell cmd appops get --user 0 com.shilapi.xcertplay.p7 WRITE_SETTINGS
```

应用内授权要求 ADB 或 Shizuku 已经可用，不会开启关闭中的 ADB。开机、休眠唤醒后的自动恢复效果依固件而定。

## 仪表导航

**目前仅测试高德地图，其他地图应用未验证。**

1. 进入 OP「仪表导航」，选择「本机 ADB 启动」或「通过 Shizuku 启动」，完成授权。
2. 让原车仪表显示导航卡片。
3. 连接 CarPlay，在高德地图中开启导航。

仪表启动与热点授权相互独立。只授权热点，不会自动获得仪表投放能力。

| 状态 | 含义 |
| --- | --- |
| 等待 CarPlay | 主连接尚未就绪 |
| 等待 iPhone 独立地图 | 主屏已连接，第二路还没有有效画面 |
| 等待原车导航卡片 | 仪表当前没有请求地图区域 |
| 通道运行中 | 正在向原车接口提交画面 |

充电等原车页面可能覆盖导航卡片。仪表地图的范围、3D 和车道级内容由高德决定，可能与中控不同。

## 原车蓝色车道条

「OP 投放时隐藏原车车道提示」默认开启，可在设置中关闭。

OP 投放时持续隐藏蓝条；退出、断开或关闭选项后停止隐藏。有本轮车道缓存时尝试恢复，无缓存时等待原车下一次更新，因此旧蓝条可能不会立刻重现。

## 更新与退出

同包名、同签名的更新可保留设置；不同签名无法直接覆盖。较低版本号通常不能直接覆盖降级。

从内置认证文件的版本更新时，如原有认证选择失效，请重新选择自己的文件。

通过 OP 设置中的「退出应用」结束使用，并释放仪表投放。若原车小地图没有恢复，请停车后记录仪表状态并反馈。

## 反馈问题

请提供车型、系统版本、OP 版本、复现步骤和状态文字。截图或日志中请隐去热点密码、设备信息、路线及认证材料。
