# OP CarPlay

**面向老款小鹏 P7（E28 / Android 9）的 CarPlay 接收端与原车仪表地图适配。**

基于 [shilapi/xcertplay](https://github.com/shilapi/xcertplay) 二次开发，代码沿用 **GPL-3.0**。这是个人适配项目，与小鹏、Apple 无隶属或背书关系，**不是 CarPlay Ultra，也不是整块仪表的接管方案**。

当前公开快照：**v0.7 / build 1349 · 2026-10-20**。`P7` 是车型，不是版本号；`1.0` 尚未定版。

[下载安装包](https://github.com/heavendoorx7/OP-CarPlay/releases) · [使用与授权](docs/USAGE.md) · [最终功能说明](docs/FEATURES.md) · [技术说明](docs/IMPLEMENTATION.md) · [构建](docs/BUILD.md) · [测试范围](docs/VALIDATION.md)

## 功能

| 功能 | 实际行为与范围 |
| --- | --- |
| 无线 CarPlay | 使用车机原生热点与 iPhone 连接；保留上游音频、触控、麦克风和媒体能力 |
| 老 P7 三种显示方式 | 原车分屏；带原车系统栏的全屏；隐藏原车状态栏和 Dock 的完全全屏 |
| 尺寸与触控适配 | 按实际可用区域处理上下、左侧系统栏，修正全屏左上角返回触控；切换仍可能重连，并非无缝切换 |
| 中文分类设置 | 左侧分类、右侧设置，调整多按钮布局；小图标切换全屏状态，默认显示模式可配置 |
| 手势设置入口 | 五指向内收拢或三指下滑呼出设置；手指需落在 CarPlay 区域内 |
| 原生热点自动恢复 | 可选、默认关闭；尝试启动原车已有热点，保留原车频段配置，不会把不支持的热点强制变成 5 GHz |
| 两种授权入口 | 已开启且允许 OP 连接的本机 ADB；或已经运行并允许 OP 的 Shizuku |
| 独立仪表地图 | 向 iPhone 请求第二路地图，在 P7 原车导航卡片区域输出；没有中控右上角预览窗 |
| 仪表居中与限帧 | 1349 使用 1328×664 的 iPhone 输入画布和应用内居中取景，车端按实时请求输出；本车为 660×660、5 fps |
| 原车地图交接 | 投放期间暂停固定的原车小地图服务，退出时使用原车 RESET 路径重建；不停止整个原车导航应用 |
| 原车车道条隐藏 | 投放时立即隐藏蓝色车道条，可关闭，退出按缓存或原车后续事件恢复 |
| 自定义认证 | 本地证书与配套私钥、上游支持的硬件/远程认证方式；公开发行包不提供认证材料 |

## 开始使用

1. 从 Releases 下载 **public APK**，通过你已有的安装入口安装。GitHub 仅提供 APK 和开源源码，不分享离线安装工具或安装 command；本项目不提供免授权开启 ADB 的方法。
2. 打开车机原生热点，在 OP 中选择原生/手动热点方式，填写**真实热点名称、密码和安全类型**。如车机原生热点当前使用 5 GHz，OP 复用该配置。
3. 配置你有权使用的认证材料。公开 APK **不内置个人使用的证书、私钥或远程服务凭据**；首次安装需要自己选择。
4. 完成蓝牙配对，保存设置并连接 iPhone。仪表功能需另行启动仪表通道，并让原车仪表显示导航卡片。

详细步骤、两种授权的区别、更新和卸载说明见 [使用说明](docs/USAGE.md)。

## 支持与限制

- 主要适配对象是 **E28 / Android 9 / 中控 2400×1200 的老 P7**。其他 P7 年款、P7i、P7+、其他品牌及固件未被此仓库承诺兼容。
- 仪表输入画布和输出区域是两件事：1328×664 不代表仪表变成宽屏；真实仪表仍使用原车请求的导航区域。
- **仪表盘导航功能目前仅测试了高德地图；Apple 地图、百度地图等其他地图应用尚未验证。** 第二路内容由 iPhone 和地图应用决定，不保证与中控画面完全一致；3D/车道级效果也受高德自身导航模式影响。
- 上游有 USB/有线相关代码，但 **本项目没有完成老 P7 有线 CarPlay 实车验收**。
- 自动热点依赖原车服务、权限及固件；有开关或授权成功不等于所有车辆重启、休眠唤醒后都能成功。
- 断流、退出和异常恢复有保护逻辑，但不能保证所有进程同时被强杀、系统故障等情况下立即恢复原车画面。
- 这是实验性社区版本。本地测试通过不等于全部道路、所有固件或完整安全审计通过。设置与安装请在停车时操作。

## 源码与构建

```bash
git clone https://github.com/heavendoorx7/OP-CarPlay.git
cd OP-CarPlay
# 先准备 JDK 25、Android SDK/NDK，详见 docs/BUILD.md
bash scripts/build-p7.sh :common:testDebugUnitTest :shared:testDebugUnitTest :mobile:assembleDebug
```

`mobile` 是此 P7 版本的应用目标；`automotive` 保留上游工程结构，但不是本次老 P7 发行目标。

源码包含 1349 的生产逻辑、测试和构建入口，不包含离线安装工具。公开 APK 使用同一应用逻辑构建，区别是**没有注入个人认证文件**。签名私钥、车机固件、原厂 APK/反编译资料、实车原始日志与个人网络配置均不在仓库中。
